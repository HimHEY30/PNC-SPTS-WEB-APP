# <i class="ti ti-school" style="color: #10b981; font-size: 32px; vertical-align: middle;"></i> PNC SPTS Web App

> **Student Follow-Up System** — A centralized platform for monitoring student activities, managing follow-up records, and tracking progress through a chronological timeline.

---

## <i class="ti ti-star" style="color: #ffe066; font-size: 22px; vertical-align: middle;"></i> Key Features

* <i class="ti ti-columns-2" style="vertical-align: middle; margin-right: 4px;"></i> **Student Directory & Profiles** — A clean, searchable dashboard to quickly view individual student files.
* <i class="ti ti-notebook" style="vertical-align: middle; margin-right: 4px;"></i> **Follow-Up Management** — An easy-to-use form for teachers to log new monitoring records, categorize incident types, and assign severity levels.
* <i class="ti ti-paperclip" style="vertical-align: middle; margin-right: 4px;"></i> **Document Attachments** — Secure file uploading to attach supporting documentation (PDFs, images, or forms) directly to any specific record.
* <i class="ti ti-history" style="vertical-align: middle; margin-right: 4px;"></i> **Chronological Timeline** — A unified, historical activity feed for each student that automatically orders notes, status updates, and uploaded files by date.

## <i class="ti ti-rocket" style="color: #10b981; font-size: 22px; vertical-align: middle;"></i> Getting Started

### <i class="ti ti-device-desktop" style="vertical-align: middle; margin-right: 4px;"></i> Prerequisites

Make sure you have <i class="devicon-nodejs-plain colored"></i> Node.js installed (version `^20.19.0` or `>=22.12.0` is recommended).

### <i class="ti ti-download" style="vertical-align: middle; margin-right: 4px;"></i> Installation

    npm install

### <i class="ti ti-device-laptop" style="vertical-align: middle; margin-right: 4px;"></i> Local Development

    npm run dev

### <i class="ti ti-building" style="vertical-align: middle; margin-right: 4px;"></i> Production Build

    npm run build
